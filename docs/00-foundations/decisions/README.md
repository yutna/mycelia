# Decision records

Status: Active

This directory holds the Architecture Decision Records (ADRs) for Mycelia. The
format and the rule for when a decision needs a record are in
[GOVERNANCE.md](../../../GOVERNANCE.md#decision-records).

## Conventions

- File name: `NNNN-short-title.md`, numbered in order and never reused.
- Sections: status, context, decision, consequences, and related documents.
- Status is one of `proposed`, `accepted`, `superseded`, or `rejected`.
- An accepted record is not edited for substance. A new record supersedes it
  and both records link to each other.
